# 16 -Product Listing UI (21-03)

## Description
"Aether E-Commerce" is a premium product discovery interface. It serves as a mini e-commerce frontend, allowing users to browse, filter, and search through a curated collection of products with a high-end feel.

## Features
- **Dynamic Search**: Real-time filtering by product name or description.
- **Advanced Filtering**: Categorize products and use a price range slider (up to ₹1500).
- **Product Discovery**: High-quality product cards with interactive hover states.
- **Shopping Cart**: Real-time cart counter that updates as items are added.
- **Responsive Layout**: Sidebar-driven navigation optimized for desktop and mobile discovery.
- **Premium Aesthetics**: High-end typography and clean grid layouts.

## Tech Stack
- **Library**: React (useMemo optimization)
- **Build Tool**: Vite
- **Styling**: CSS3 (Grid & Flexbox)
- **Icons**: Lucide/FontAwesome (compatible)

## Installation and Setup
1. Navigate to the project folder.
2. Run `npm install`.
3. Run `npm run dev`.

## Prerequisites
- Node.js (LTS version).
