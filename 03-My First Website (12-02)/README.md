# 3 -My First Website (12-02)

## Description
A modern, visually appealing personal profile website. This project marks the transition from static layouts to dynamic aesthetics, featuring animated gradients and glassmorphism design.

## Features
- **Animated Background**: Smooth 400% size gradient animation for a lively feel.
- **Glassmorphism**: Soft, blurred background containers for a premium look.
- **Hover Effects**: Interactive image scaling and card transformations.
- **Fully Responsive**: Adapts seamlessly to different screen sizes.
- **Google Fonts Integration**: Uses "Inter" for modern typography.

## Tech Stack
- **Structure**: HTML5
- **Styling**: CSS3 (Vanilla)
- **Fonts**: Google Fonts (Inter)
