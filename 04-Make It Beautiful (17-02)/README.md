# 4 -Make It Beautiful (17-02)

## Description
An advanced iteration of a personal profile website, emphasizing "premium" aesthetics. This project focuses on high-end UI/UX elements, including neon glows, interactive navigation, and animated progress bars.

## Features
- **Premium UI**: Dark mode aesthetic with neon accents and deep shadows.
- **Sticky Navigation**: Smooth, responsive navbar that stays pinned to the top.
- **Interactive Skills**: Animated skill bars that load with ease-out effects.
- **Glowing Profile**: Profile image with a rotating, colorful gradient border.
- **Font Awesome Icons**: Rich iconography for social links and section titles.
- **Smooth Scrolling**: Enhanced user navigation within the page.

## Tech Stack
- **Core**: HTML5, CSS3
- **Icons**: Font Awesome 6.4.0
- **Typography**: Google Fonts (Poppins)
