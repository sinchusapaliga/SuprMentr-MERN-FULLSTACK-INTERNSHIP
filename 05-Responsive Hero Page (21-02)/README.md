# 5 -Responsive Hero Page (21-02)

## Description
A state-of-the-art, responsive hero landing page built using modern CSS Flexbox. This project demonstrates advanced layout techniques, mobile-first design, and glassmorphism UI components.

## Features
- **Flexbox Mastery**: Entire layout built using CSS Flexbox for maximum flexibility.
- **Glassmorphism**: Blurred panels with thin borders and deep shadows.
- **Mobile Responsive**: Fully optimized for desktops, tablets, and smartphones.
- **Micro-Animations**: Pulse effects for badges, floating visual elements, and smooth button transitions.
- **Gradient Text**: Eye-catching typography using background-clip: text.
- **3D Visuals**: Includes a floating 3D hero asset with glow rings.

## Tech Stack
- **Markup**: HTML5
- **Styling**: CSS3 (Vanilla, Flexbox focus)
- **Typography**: Outfit & Inter (Google Fonts)
- **Icons**: Font Awesome
