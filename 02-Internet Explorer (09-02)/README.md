# 🌐 2-Internet Explorer (09-02)

## 📖 Overview
This folder contains foundational research and documentation on **Client-Server Architecture**. It explains the core mechanics of how the internet functions and what happens behind the scenes when a user opens a website.

## 🎯 Key Topics Covered
- **Client-Server Model**: The relationship between a user's device (client) and the powerful computers (servers) that store website data.
- **The Lifecycle of a Request**: A step-by-step trace of a website request—from DNS lookups to final browser rendering.
- **Network Components**: Understanding the roles of Databases, DNS, and the Internet in web communication.
