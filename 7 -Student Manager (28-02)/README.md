# 7 -Student Manager (28-02)

## Description
A JavaScript-based student data management script. It processes a collection of student records, performing calculations on their grades and providing a clear performance summary.

## Features
- **Data Modeling**: Uses objects to store student names and their respective marks.
- **Average Calculation**: Iterates through mark arrays to find the arithmetic mean.
- **Console Reporting**: Displays each student's name and their calculated average in a clean, formatted manner.

## Tech Stack
- **Language**: JavaScript (Node.js or Browser compatible)

## Installation and Setup
### Browser Method:
1. Create a simple `index.html` and link `studentmanager.js` to it.
2. Open the HTML file and check the console.

### Node.js Method:
1. Ensure Node.js is installed.
2. Run the command: `node studentmanager.js`

## Prerequisites
- Node.js (Optional) or any modern browser.
