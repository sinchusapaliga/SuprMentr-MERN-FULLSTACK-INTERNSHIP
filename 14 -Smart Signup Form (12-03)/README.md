# 14 -Smart Signup Form (12-03)

## Description
"Smart Signup" is a React-powered registration system that prioritizes user experience and data integrity. It features real-time validation and a "smart" interface that guides users through the account creation process.

## Features
- **Instant Validation**: Provides immediate feedback on input errors (email format, password strength).
- **Component-Based Logic**: Encapsulates form logic within a reusable `SignupForm` component.
- **Intuitive UI**: Modern design with clear labels and focused input states.
- **Responsive Design**: Scales perfectly to any screen size.

## Tech Stack
- **Frontend**: React
- **Build Tool**: Vite
- **Styling**: Vanilla CSS

## Installation and Setup
1. Open terminal in this directory.
2. Run `npm install`.
3. Run `npm run dev`.

## Prerequisites
- Node.js installed on your system.
