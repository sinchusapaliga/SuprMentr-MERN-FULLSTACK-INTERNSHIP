# 🔍 9 - Component Hunt (05-03)

## 📖 Overview
This project involves a detailed UI/UX analysis of **Instagram**, breaking down its complex interface into a structured hierarchy of reusable components.

## 🎯 Key Topics Covered
- **Component Hierarchy**: Analyzing how the application is divided into major sections like the Navigation Sidebar, Main Content Layout, and Right Side Panel.
- **UI Breakdown**: Examining the internal structure of features like the **Stories Section**, **Feed Container**, and individual **Post Cards**.
- **Modular Design**: Identifying nested components (Avatars, Action Bars, Metadata) to understand how modern apps build scalable and maintainable UIs.
