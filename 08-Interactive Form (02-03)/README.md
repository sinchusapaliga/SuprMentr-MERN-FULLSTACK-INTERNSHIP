# 8 -Interactive Form (02-03)

## Description
A highly interactive and visually polished registration form. This project features robust client-side validation, modern UI/UX principles, and interactive feedback mechanisms.

## Features
- **Real-time Validation**: Validates name, email (regex), and password (length) upon submission.
- **Visual Feedback**: Dynamic success/error icons and shaking animations for invalid inputs.
- **Password Visibility**: Interactive "eye" icon to toggle password visibility.
- **Simulated API Flow**: Loading spinner on the submit button followed by a beautiful success overlay.
- **Modern Aesthetics**: Uses Google Fonts (Poppins), Font Awesome, and a sleek purple/blue gradient UI.

## Tech Stack
- **Structure**: HTML5
- **Styling**: CSS3 (Vanilla)
- **Logic**: JavaScript (DOM manipulation)
- **Icons/Fonts**: Font Awesome, Poppins

## Project Structure
```
8 -Interactive Form (02-03)/
├── index.html    # Form structure
├── style.css     # Advanced styling & animations
└── script.js     # Validation & UI logic
```

1. Navigate to the `8 -Interactive Form (02-03)` folder.
