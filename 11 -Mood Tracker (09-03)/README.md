# 11 -Mood Tracker (09-03)

## Description
"MoodBoard" is a personal well-being application designed to track and visualize daily moods. It provides a simple yet effective way to maintain an emotional journal with context-rich notes.

## Features
- **Interactive Mood Selection**: Choose from various moods with instant visual feedback.
- **Dynamic Themes**: The entire app background and "orbs" change color based on the selected mood.
- **Mood History**: Keeps a log of the last 10 entries with timestamps and personal notes.
- **Responsive Layout**: Optimized for both desktop and mobile logging.
- **Polished UX**: Smooth transitions and modern "orb" background animations.

## Tech Stack
- **Frontend**: React
- **Build Tool**: Vite
- **Styling**: CSS3 (Dynamic classes & animations)

## Installation and Setup
1. Navigate to the project directory.
2. Run `npm install` to set up dependencies.
3. Execute `npm run dev` to launch the app.

## Prerequisites
- Node.js installed.
- Modern browser.
