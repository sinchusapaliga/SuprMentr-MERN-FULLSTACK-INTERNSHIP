# 6 -Console Challenge (24-02)

## Description
A functional JavaScript calculator designed to be executed and tested within the browser's developer console. This project demonstrates basic functional programming and logic handling in JS.

## Features
- **Math Operations**: Supports Addition, Subtraction, Multiplication, and Division.
- **Error Handling**: Includes logic to prevent division by zero.
- **Console Feedback**: Outputs results directly to the browser console for debugging.

## Tech Stack
- **Languages**: HTML5, JavaScript (ES6)

## Project Structure
```
6 -Console Challenge (24-02)/
├── index.html    # Contains the logic and structure
└── Output.png    # Preview of the console results
```

## Installation and Setup
1. Navigate to the `6 -Console Challenge (24-02)` folder.
2. Open `index.html` in your browser.
3. Pulse `F12` or `Ctrl+Shift+I` to open the Developer Tools.
4. Go to the **Console** tab to see the calculated outputs.

## Prerequisites
- Modern Web Browser (Chrome, Firefox, etc.)
