# 1-Resume (07-02)

## Description
A professional single-page resume built to showcase personal achievements, technical skills, and internship experiences. The project focuses on clean typography and a structured layout for maximum readability.

## Features
- **Clean UI**: Professional design with a focused layout.
- **Contact Integration**: Clickable links for email, LinkedIn, and GitHub.
- **Structured Sections**: Clear headers for Career Objective, Internships, Education, Projects, and Skills.
- **Responsive Typography**: Uses Arial/Helvetica with clear hierarchy.

## Tech Stack
- **Languages**: HTML5, CSS3 (Internal styling)

## Project Structure
```
1-Resume (07-02)/
└── resume.html
```

## Installation and Setup
1. Clone the repository.
2. Navigate to the `1-Resume (07-02)` folder.
3. Open `resume.html` in any modern web browser.

## Prerequisites
- A modern web browser (Chrome, Firefox, Edge, etc.)
